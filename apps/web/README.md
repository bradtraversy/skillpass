# apps/web

The static SkillPass front end: Astro pages with React islands for the
interactive parts. Commands, conventions, and the workflow live in the root
`README.md` and `AGENTS.md`; run everything from the repo root.

```
pnpm dev        # dev server at http://localhost:4321
pnpm typecheck  # astro check
pnpm build      # astro check && astro build
```
